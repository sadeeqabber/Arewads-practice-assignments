## Submitted Assignments

### Week 1: Self-Paced Python Practice Lab
The `print()` function, variables and assignment, `input()`, type conversion with `int()` and `float()`, understanding syntax errors, and challenge problems (area calculator, shopping bill, personal information display).
[Open notebook](assignments/week1_lab_muhammad_abubakar_sadiq.ipynb)

### Week 2: First Programs, Data, Variables, and Expressions
Quotes and escape sequences, literals and data types, string operations, variable naming and constants, comments and docstrings, arithmetic precedence, mixed-mode arithmetic, user input, functions and modules, `ord` and `chr`, plus exercises such as change maker and compound interest.
[Open notebook](assignments/week2_lab_muhammad_abubakar_sadiq.ipynb)

### Week 3: Selection and Loops
Booleans and comparisons, `if`, `if-else` and `elif`, logical operators, short-circuit evaluation, `for` and `while` loops, the accumulator pattern, off-by-one errors, string traversal, and random numbers. Exercises include a ticket price calculator, multiplication table, FizzBuzz, digit sum, leap years and grade statistics.
[Open notebook](assignments/week3_lab_muhammad_abubakar_sadiq.ipynb) · [Expanded version](assignments/week3_lab_muhammad_abubakar_sadiq_1.ipynb)

### Week 7: Lists and Dictionaries
List operations and tasks such as `count_even`, `above_average` and `tally`, plus a Level 3 task computing averages per student from a file.
[Open notebook](assignments/week7_lab_muhammad_abubakar_sadiq.ipynb)

### Week 8: Functions
Session A covers defining and calling functions, parameters, `return`, how a call works, and docstrings. Session B covers top-down design with stubs and `main()`, default and keyword arguments, testing with `assert`, reusable looping functions such as `is_prime`, and refactoring.
[Open notebook](assignments/week8_lab_muhammad_abubkar_sadiq.ipynb)
